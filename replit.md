# Munib Hamza - iOS Developer Portfolio

## Project Overview
A modern, interactive portfolio website for iOS developer Munib Hamza featuring a dark, stylish Scandinavian design with animated project cards and contact integration.

## User Preferences
- Prefers dark color schemes that are more attractive and stylish
- Wants modern, interactive elements with animations
- Scandinavian-style minimalist design
- Focus on showcasing iOS development work

## Project Architecture
- **Frontend**: React with TypeScript
- **Styling**: Tailwind CSS + shadcn/ui components
- **Animations**: Framer Motion for smooth interactions
- **Routing**: Wouter for single-page navigation
- **Forms**: React Hook Form with Zod validation
- **Icons**: Lucide React + React Icons
- **Backend**: Express.js for contact form handling
- **Storage**: In-memory storage for contact messages

## Key Features
1. Dark-themed hero section with professional photo and CTA
2. Interactive project cards with hover animations
3. Skills section with visual progress indicators
4. About Me section with personal background
5. Contact form with email integration
6. Responsive design for all devices
7. Smooth scrolling navigation
